# 素材目录

所有素材按用途分目录放置，避免混在一起：

| 目录 | 放什么 |
| --- | --- |
| `sprites/` | 角色、精灵、NPC、动物等独立精灵图 |
| `tilesets/` | Kenney Tiny 系列的整图 tilemap（Farm / Town / Dungeon） |
| `audio/` | 音效和音乐 |

## 计划使用的素材

- Kenney **Tiny Farm**：作物、家畜、农具、谷仓（农场玩法核心）
- Kenney **Tiny Town**：城镇建筑、地形、植被（村庄地图）
- Kenney **Tiny Dungeon**：室内/矿洞瓦片、武器、物品、角色
- Kenney **Tiny Battle**：战斗单位（做战斗时再加入）

均为 CC0，16×16 像素，可自由用于练习和商业项目。下载后把 zip 里的
PNG 按用途解压到对应目录，Godot 会自动导入。

精灵相关的素材（精灵本体、进化形态、孵化特效）Kenney 系列没有现成的，
后续需要自己画或找风格匹配的素材，这是本项目唯一的素材缺口。
