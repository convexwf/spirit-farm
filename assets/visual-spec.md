# 精灵视觉规范（v0.1）

> 目的：让所有精灵素材（AI 生成、手绘、现成素材包）进游戏时风格统一。
> 核心前提：**瓦片尺寸和精灵尺寸是解耦的**——瓦片锁 16×16，
> 精灵按角色重要程度用更大的画布。

## 1. 尺寸分级

| 对象 | 画布 | 说明 |
| --- | --- | --- |
| 世界瓦片 | 16×16 | **锁定**，匹配 Kenney Tiny 系列 |
| 普通小精灵 | 16×16 | 数量多、非主角，可低规格 |
| 玩家 / 陪伴精灵 / 会进化的精灵 | 32×32 | 游戏门面，大头圆身才有表达空间 |
| NPC | 32×32 | 与玩家同规格 |

可选中间档 24×24，但全项目最多用 16 / 24 / 32 三档，避免规格膨胀。

## 2. 锚点与碰撞（最重要）

- 所有角色**脚底中心对齐所在瓦片中心**（bottom-center = tile center）；
- 外观可以高 1~2 格（32×32 精灵约等于 2 瓦片高），y-sort 正常遮挡；
- 占格碰撞统一按 1×1 算，外观大小不影响通行判断；
- Godot 实现：精灵原点设在中下，所在节点开启 y-sort。

## 3. 可爱化比例（参考《永瀑镇》Everafter Falls）

永瀑镇精灵可爱靠的是**比例和配色**，不是像素密度：

- 头约占画布高度的 40~50%，眼睛大、位置偏下；
- 身体小且圆润，四肢短；
- 圆翅膀，漂浮系精灵不画腿或只画小短腿；
- 柔和色为主 + 少量高饱和点缀；
- 1px 深色描边（对齐 Kenney Tiny 风格）。

## 4. 元素配色（让玩家一眼识别）

| 元素 | 主色 |
| --- | --- |
| 火 | 红 / 橙 |
| 水 | 蓝 |
| 草 | 绿 |
| 土 | 棕 |
| 风 | 青 |
| 光 | 黄 / 白 |
| 暗 | 紫 |

## 5. 动画帧结构（漂浮精灵）

精灵是飘着的，**不需要 4 方向行走帧**，动画成本大幅下降：

| 动画 | 帧数 | 说明 |
| --- | --- | --- |
| idle | 2 | 上下浮动，循环 |
| wing | 2 | 翅膀扇动，可与 idle 叠加（或合并成 4 帧单循环） |
| work | 2~4 | 干活动作（浇水/播种）；远景可用特效代替 |
| hurt / cast | 各 1~2 | 战斗相关，v0.4 再加 |

进化 = 新 sprite sheet，同一规格，只是形态不同。

## 6. 文件命名与目录

```text
assets/sprites/spirits/<species>/
  <species>_<form>_<anim>.png    # 每动画一张横排多帧图
```

示例：`emberling_v1_idle.png`（2 帧横排，导入后 Hframes=2）。

- 动画图横向排列帧，帧间距 0；
- 透明背景 PNG；
- 画布尺寸必须是 16 的倍数。

## 7. 调色板

- 全部素材优先使用 Kenney Tiny 系列现有调色板（下载 Tiny Farm / Town / Dungeon 后统一提取）；
- AI 生成素材必须量化到该调色板后再入库；
- 提取方法：从现有 PNG 用脚本提取唯一颜色生成调色板文件，我可以直接代做。

## 8. 导入 Godot

- 工程已配 Nearest 过滤 + 像素吸附（`project.godot` 已设好）；
- 相机 zoom 3x：16 瓦片 = 48 屏幕像素，32 精灵 = 96 屏幕像素（约 2 瓦片高）；
- 用 `AnimatedSprite2D` 按 Hframes 切帧，或放进 TileSet 做动画瓦片。
