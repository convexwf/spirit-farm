## 1. 识别规则与边界

两张图都是 192×176 像素，按 12 列 × 11 行切分，每格 16×16 像素。编号规则为：

```text
index = 行 × 12 + 列
```

原图：

- [Tiny Town tilemap_packed.png](../assets/kenney/tiny-town/Tilemap/tilemap_packed.png)
- [Tiny Farm tilemap_packed.png](../assets/kenney/tiny-farm/Tilemap/tilemap_packed.png)

以下描述根据像素内容和用途进行人工归类，不代表 Kenney 官方对象名称。`拼接片`表示该瓦片需要和相邻瓦片组合成完整树、栅栏或建筑；`未知/装饰`表示仅凭图集无法确定用途。

作物阶段只能按视觉近似归组，图集本身没有 stage 元数据。例如 `[4, 5, 6, 8]` 可以作为橙色根茎作物变体，但不应直接断言它们严格对应 stage 0、1、2、3。

## 6. 代码接入注意事项

当前 `scripts/core/farm_map.gd` 中有几处需要按本索引修正：

```gdscript
# 61 不是水，而是 Tiny Town 的红色建筑瓦片。
const WATER := 61

# 7 不是独立灌木，而是绿色树冠/树木拼接片。
const BUSH := 7

# Tiny Town 的 29 是红色蘑菇/小花，不是普通黄色花。
const FLOWER := 29
```

Tiny Town 的水面地形应标记为“无”。Tiny Farm 的 `110、111` 更像水槽/水池对象，而不是可铺设的水面地形。
