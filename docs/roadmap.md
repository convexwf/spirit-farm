## 1. 维护说明

本文件是 [design.md](design.md) 的执行视图：只列"要做什么"和"做完了没有"，不重复设计理由。勾选完成某项时，同步检查 design.md 中对应的约束和检查项是否需要更新。扩展创意池内容见 design.md 第 7 章，不在此重复铺开。

## 2. 视觉打磨

背景：16×16 瓦片足够（星露谷同规格），当前"简陋感"来自素材使用方式而非分辨率。以下按性价比排序。

- [ ] 角色两格高：玩家与关键精灵画布 32×32（2 瓦片高），补 4 方向待机/行走动画（高优先级，规则见视觉规范）
- [ ] 地形边缘过渡：使用 Kenney 自带的 3×3 边缘瓦片组，按邻居检测自动铺草地/泥土/水塘边界（高优先级）
- [x] 阴影：玩家、树木、建筑底部增加椭圆软阴影（高优先级，首轮完成）
- [x] 昼夜色调：CanvasModulate 随游戏时间调色，傍晚暖光（高优先级，首轮完成）
- [x] 地面细节层：草地撒草叶、小花、小石子等非碰撞点缀，替代整块随机换瓦片（中优先级，首轮完成草叶/小花）
- [ ] 调色统一：素材入库时量化到 Tiny 调色板，统一描边与明度（中优先级，配合素材处理）
- [ ] 地图构图：加入建筑、围栏、路径走向变化，避免大块矩形测试场（低优先级）

## 3. 核心玩法闭环

- [x] 地图 + 移动 + 碰撞 + 相机（v0.1 已完成，2026-08-30）
- [x] 时间系统 + HUD（v0.1 已完成，一天约 2.4 分钟）
- [x] 农场闭环雏形：锄地/浇水/播种/生长/收获，收获结算金币（v0.1 已完成）
- [ ] 浇水规则化：当天未浇水的作物不生长（当前是无条件每天长一阶段）

## 4. 精灵系统

- [ ] v0.2 第一只精灵：喂食升级 + 代办浇水
- [ ] 收获结灵：按品质 × 照料度结算概率（CropData 字段已预留）
- [ ] 孵化：喂指定作物 + 等待若干天
- [ ] 心情系统：偏好食物、罢工或消极怠工（v0.3，按行为实现而非纯数值）
- [ ] 多精灵 + 多种代办：锄地/播种/收割（v0.3）
- [ ] 进化分支：等级 + 喂食 + 心情 → 新形态/新技能（v0.5，EvolutionData）
- [ ] 精灵图鉴（v0.5）
- [ ] 扩展创意池（未锁定）：灵屋/祭坛、谱系繁殖、季节限定灵、月相与节日、玩家羁绊（见 design.md 第 7 章）
